## 個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
測試一的 `board_list` 為 `['amy', 'ben', 'amy', 'cora']` 共 4 筆，但 `'amy'` 是同一人在同一場活動重複報名，依規則同一場只算一位參加者且只收一次費用，去重後為 `['amy', 'ben', 'cora']` 共 3 人，因此桌遊費用為 `3 × 120 = 360.00` 元。
- **直接把字串拆成 `list`**：**保留**了原始出現順序與重複報名次數（可觀察到重複情形），但**失去**了「單場不重複參加者」的唯一性，若直接用 `len(list)` 計費會多算重複者。
- **再轉成 `set`**：**保留**了不重複的參加者元素並可做交集、聯集、差集運算，但**失去**了原本的排列順序與重複出現的次數。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
在測試三中，設桌遊集合為 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合為 $M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，兩場去重後完全相同（$B = M$）：
- 聯集 $B \cup M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，所以「總不重複人數」為 $|B \cup M| = 3$ 人。
- 但每位參加者都同時參加了桌遊與電影兩場（$B \cap M = B \cup M$），因此「報名人次」是兩場去重人數相加：$|B| + |M| = 3 + 3 = 6$ 人次。
- 費用採各場分別計費：
  - 桌遊應收：$3 \times 120 = 360.00$ 元
  - 電影應收：$3 \times 80 = 240.00$ 元
  - 總應收：$360.00 + 240.00 = 600.00$ 元
